# Project brief

Transmission Line Studio is a Windows desktop app for CAPSA / Power System Analysis students. It computes stranded-conductor GMR and transmission-line GMD, inductance, capacitance, and reactances, while showing geometry and report-ready working. The engine stays pure Python and SI-based; the UI and optional AI extraction are separate. See [PRD](../docs/PRD.md), [architecture](../docs/ARCHITECTURE.md), [design](../docs/DESIGN.md), [phases](../docs/PHASES.md), [memory rules](../docs/MEMORY_RULES.md), and [AI upgrade](../docs/ai_upgrade.md).
